## 完整知识清单

### 协议、电平与帧

- [ ] 说清 USART、I2C、SPI、CAN、USB 在线数、单双工、同步/异步、电平和网络拓扑上的区别。
- [ ] 全双工 TX/RX 必须交叉连接且共地；单向只接一个数据方向；STM32 端使用 3.3 V TTL，不能直接接 RS232 的正负高压。
- [ ] 区分 TTL（单端）、RS232（反相且高电压）与 RS485（差分）；知道需要相应收发/电平转换器。
- [ ] 帧由空闲高、起始低、数据位（通常 LSB 先发）、可选校验、停止位组成；双方波特率、字长、校验、停止位必须一致。
- [ ] 波特率是每秒符号数；8N1 的 1 字节占 10 bit，理论有效字节率约为 `baud/10`。
- [ ] 理解 16 倍过采样、起始位侦测和多数采样的抗噪作用；能从逻辑分析仪波形读出 0x55/0xAA。

### USART 外设与 SPL

- [ ] 画出 TDR/发送移位寄存器/TX 与 RX/接收移位寄存器/RDR 的路径。
- [ ] USART1 在 APB2；PA9 为 `GPIO_Mode_AF_PP` TX，PA10 为输入 RX；课程代码用 PA10 上拉输入。
- [ ] 掌握 `USART_InitTypeDef` 的 BaudRate、WordLength、StopBits、Parity、HardwareFlowControl 和 Mode。
- [ ] 区分 TXE（发送数据寄存器空）、TC（整帧发送完成）、RXNE（接收数据寄存器非空）、IDLE、ORE、NE、FE、PE；选择标志必须符合目的。
- [ ] 发送顺序：等 TXE → 写 DR；需要立刻关闭收发器或改方向时最后还要等 TC。
- [ ] 接收可轮询 RXNE，也可使能 RXNEIE + NVIC；ISR 应短小，只取 DR、推进状态机/写缓冲并置 `volatile` 标志，不在 ISR 内 OLED 刷屏或阻塞发送。
- [ ] 读 SR 后读 DR 可按手册序列清除部分接收错误/RXNE；不要机械清标志，要查每一位的清除方式。
- [ ] 能实现 `Serial_SendByte`、Array、String、Number；理解 `fputc` 重定向 `printf`、`sprintf` 的代价和格式风险。
- [ ] 波特率计算：`USARTDIV=fPCLK/(16×baud)`；BRR 高 12 位为整数部分、低 4 位为 1/16 小数，量化后计算实际波特率和误差。

### 数据包与状态机

- [ ] 区分串口助手 HEX 模式（原始字节）与文本模式（字符编码）；`'A'` 对应 `0x41`。
- [ ] 固定长度 HEX 包：`FF D0 D1 D2 D3 FE`；状态 0 等包头、状态 1 收 4 字节、状态 2 等包尾。
- [ ] 可变长度文本包：`@payload\r\n`；状态 0 等 `@`、状态 1 收内容/等 `\r`、状态 2 等 `\n`。
- [ ] 为缓冲区保留字符串终止 `\0`；检查 `index < sizeof(buf)-1`，超长立即丢包并复位，不允许越界。
- [ ] 处理噪声、半包、连续包、错尾、包内新包头、空包；定义一致的丢弃/重同步策略，而不是只验证理想包。
- [ ] ISR 与主循环共享的完成标志/索引要考虑 `volatile`、原子读写和“消费后清零”；主循环处理期间避免 ISR 覆盖尚未消费的数据。

### 下载工具

- [ ] FlyMcu 走芯片系统 Bootloader：确认 BOOT0/BOOT1、电平、串口和复位步骤；下载后恢复从用户 Flash 启动。
- [ ] ST-LINK Utility 使用 SWD，可连接、擦除、下载、校验、查看存储；不能把工具显示成功当作应用功能验证。

### 必会公式

```text
USARTDIV = fPCLK / (16 × baud)
实际波特率 = fPCLK / (16 × 量化后的USARTDIV)
波特率误差(%) = (实际 - 目标) / 目标 × 100%
8N1每字节位数 = 1起始 + 8数据 + 0校验 + 1停止 = 10 bit
理论有效字节率 = baud / 10
发送N字节最短时间 ≈ N × 10 / baud
```

- TX 接 TX、RX 接 RX或未共地；按双自环法定位。
- PC 115200、MCU 9600，观察乱码并从位宽估算实际波特率。
- 把 TXE 等待错写成 TC 或把 RXNE 当作 TC，解释卡住/吞字节现象。
- 去掉 `volatile`、在 ISR 中加入长延时/OLED 刷屏，分析优化与丢包风险。
