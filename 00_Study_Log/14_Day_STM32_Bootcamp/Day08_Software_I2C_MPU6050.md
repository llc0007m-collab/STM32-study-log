## 完整知识清单

### I2C 电气与总线规则

- [ ] I2C 是同步、半双工、主从式双线总线：SCL 提供时钟，SDA 传数据。
- [ ] SCL/SDA 采用开漏/开集电极加上拉；器件只主动拉低，高电平由上拉产生，因此可实现线与、多设备共享、仲裁和应答。
- [ ] 总线空闲为 SCL=1、SDA=1；“写 1”本质是释放线路，不是推挽强驱高。
- [ ] 上拉常见 4.7 kΩ，但实际由总线电容、速度、器件下拉能力计算；确认模块是否已自带上拉，避免并联过小。
- [ ] 知道多主仲裁和时钟延展：发送 1 却读到 0 的主机失去仲裁；从机可拉住 SCL。课程软件实现未完整支持这两项，需明确局限。

### 六个基本时序单元

- [ ] START：SCL 高期间 SDA 由高到低；之后拉低 SCL 占用总线。
- [ ] STOP：先保证 SDA 低，SCL 释放为高，再让 SDA 低到高。
- [ ] 发送字节：MSB 先发；SCL 低时改变 SDA，SCL 高时从机采样，共 8 位。
- [ ] 接收字节：主机先释放 SDA；SCL 高时采样，从 MSB 到 LSB 组装；变量必须初始化为 0。
- [ ] 发送 ACK/NACK：第 9 个时钟由主机放 0/1；多字节读中除最后字节外回 ACK，最后字节回 NACK。
- [ ] 接收 ACK：主机释放 SDA，第 9 个 SCL 高期间读取；0=ACK、1=NACK；NACK 必须传播成错误而不是丢弃。

### 组合时序与地址

- [ ] 指定地址写：`S + SLA/W + ACK + REG + ACK + DATA + ACK + P`。
- [ ] 当前地址读：`S + SLA/R + ACK + DATA + NACK + P`。
- [ ] 指定地址读：`S + SLA/W + ACK + REG + ACK + Sr + SLA/R + ACK + DATA + NACK + P`；中间是重复起始，不能随意换成错误的方向。
- [ ] MPU6050 的 7 位地址为 `0x68`（AD0=0）或 `0x69`（AD0=1）；课程宏 `0xD0` 是 `0x68<<1` 的 8 位写地址。调用 API 前先确认参数需要 7 位还是已左移地址，禁止混用。
- [ ] 多字节读利用寄存器地址自动递增；每个非末字节回 ACK，最后字节回 NACK 后 STOP。

### 软件 I2C 实现

- [ ] PB10=SCL、PB11=SDA，`GPIO_Mode_Out_OD`；初始化后两线置 1 释放总线。
- [ ] `MyI2C_W_SCL/W_SDA/R_SDA` 是唯一引脚访问层；上层不得散落直接 GPIO 操作。
- [ ] 每一个 SDA 变化都检查 SCL 所处电平；必要时加入微秒延时满足最低高/低周期。
- [ ] 对任何传给 `GPIO_WriteBit`/`BitAction` 的位值做 0/1 归一；掩码结果不保证等于 1。
- [ ] 生产级实现必须加入 ACK 错误返回、SCL/SDA 等待超时和总线恢复；今天至少实现错误码和有限次数等待，禁止永久死循环。

### MPU6050

- [ ] 3 轴加速度计 + 3 轴陀螺仪，内部 16 位 ADC；原始输出范围 `-32768..32767`。
- [ ] WHO_AM_I 寄存器 `0x75`，预期读回 `0x68`（默认 AD0 不改变身份字段）。
- [ ] 课程初始化：`PWR_MGMT_1(0x6B)=0x01`、`PWR_MGMT_2(0x6C)=0x00`、`SMPLRT_DIV(0x19)=0x09`、`CONFIG(0x1A)=0x06`、`GYRO_CONFIG(0x1B)=0x18`、`ACCEL_CONFIG(0x1C)=0x18`。
- [ ] `0x18` 选择陀螺仪 ±2000 °/s 和加速度 ±16 g；灵敏度分别约 16.4 LSB/(°/s)、2048 LSB/g。
- [ ] 读取 `ACCEL_XOUT_H..GYRO_ZOUT_L`；高低字节拼成 `uint16_t` 后转 `int16_t`，保留负数符号。
- [ ] 静止平放时某一轴约 ±1 g、其余接近 0 g；陀螺静止不必精确为 0，需讨论零偏、噪声、安装方向和校准。
- [ ] DLPF 开启时典型陀螺输出率为 1 kHz，`SampleRate=GyroOutputRate/(1+SMPLRT_DIV)`；分频 9 时约 100 Hz，最终以寄存器手册配置表为准。

### 必会公式与编码

```text
7位地址转8位：Address8 = Address7 << 1
写地址 = Address8 | 0；读地址 = Address8 | 1
有符号16位拼接 = (int16_t)(((uint16_t)High << 8) | Low)
Accel_g = AccRaw / 2048.0       （±16 g档）
Gyro_dps = GyroRaw / 16.4       （±2000 °/s档）
SampleRate = GyroOutputRate / (1 + SMPLRT_DIV)
I2C上拉近似上升时间 tr ≈ 0.8473 × Rp × Cb
位值归一：logical_bit = !!(value & mask)
```

### 故障注入（至少 4 项）

- 去掉上拉或将 GPIO 改推挽，预测并记录空闲电平/通信结果。
- 交换 SCL/SDA，按“电平→START→地址 ACK”顺序定位。
- 把 7 位 `0x68` 当作 8 位地址直接发送，解释为何从机不 ACK。
- 把 `!!(Byte & mask)` 改回未经归一的掩码，解释 API 偶然可用与接口契约风险。
- 最后一个字节仍回 ACK，观察从机继续驱动意图与 STOP 时序风险。
- 断开 SDA 或让其常低，验证超时返回和 9 个 SCL 脉冲 + STOP 的总线恢复策略。

## 官方勘误与 FAQ

`D:\STM32_Library\程序源码\程序源码\程序修改说明.pdf` 的第 4 项是 **“10-1 软件 I2C 读写 MPU6050”修改**：

- 原写法 `MyI2C_W_SDA(Byte & (0x80 >> i));` 的掩码结果可能是 `0x80` 等大于 1 的非零值。
- 官方修改为 `MyI2C_W_SDA(!!(Byte & (0x80 >> i)));`，用两次逻辑非把所有非零值归一为 1；或显式 `if/else` 传 1/0。
- 读 SDA 的判断由 `if (MyI2C_R_SDA() == 1)` 改为 `if (MyI2C_R_SDA())`，表达“非零即真”。课程原 `GPIO_WriteBit` 内部有非零判断，原代码可工作，但迁移到严格要求 0/1 的实现时可能出错，因此今天一律用归一写法。

官方 STM32 FAQ 1–18 中 **Day08 没有专属条目**；不要杜撰编号。I2C NACK、超时和总线恢复作为本计划的工程化验收项。
