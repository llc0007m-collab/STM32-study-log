## 4. 完整知识清单与公式

### 4.1 Unix 时间与 C 时间库

- [ ] Unix 时间戳是从 `1970-01-01 00:00:00 UTC` 起经过的秒数，课程定义不计闰秒；同一瞬间各时区时间戳相同。
- [ ] 本地时间换算：`UTC = LocalTime - UTCOffset`；北京时间 `UTC+8`，故 `UTC = Beijing - 8 × 3600`。
- [ ] GMT 基于地球自转；UTC 基于原子时，并用闰秒保持与地球自转差不超过约 0.9 秒；工程中不能把 GMT、UTC 和“北京时间”混作一个数。
- [ ] `time_t` 保存秒计数；若采用有符号 32 位会遇到 2038 范围问题，RTC 硬件 CNT 是 32 位无符号计数器。
- [ ] `struct tm`：`tm_year` 从 1900 起算，`tm_mon` 为 0～11；日、时、分、秒字段必须做合法性检查。
- [ ] `time()` 获取系统时钟；`gmtime()` 按 UTC 解码；`localtime()` 按运行库当地时区解码；`mktime()` 把当地日历时间编码为时间戳。
- [ ] `ctime()`、`asctime()` 输出默认字符串；`strftime()` 按格式输出；理解这些函数可能返回静态缓冲区且非重入。
- [ ] 能解释教程 `mktime(...) - 8*60*60` 与读取时 `RTC_CNT + 8*60*60` 的意图，并说明若 C 运行库已配置本地时区，必须避免重复偏移。

### 4.2 BKP 与后备域

- [ ] BKP 在 VDD 为 2.0～3.6 V 时由主电源供电，VDD 断开后可由 1.8～3.6 V 的 VBAT 保持。
- [ ] STM32F103C8T6 属中容量器件：DR1～DR10，每个 16 位，共 20 字节；不能误按大容量器件 DR1～DR42 设计。
- [ ] 系统复位、从待机唤醒不会自动清除 BKP；后备域复位或 TAMPER 事件可清除相应内容。
- [ ] BKP 还承担 RTC 校准和 PC13-TAMPER-RTC 输出选择；理解 PC13 驱动能力限制。
- [ ] 访问顺序：使能 APB1 的 PWR/BKP 时钟，再置 PWR_CR.DBP（`PWR_BackupAccessCmd(ENABLE)`）。
- [ ] 使用魔数（教程为 `BKP_DR1 = 0xA5A5`）区分“首次配置”和“后备域已配置”；能说明仅靠魔数的碰撞风险及版本号/CRC 改进方案。

### 4.3 RTC 数据流、时钟与访问规则

- [ ] 三种 RTCCLK：LSE 通常 32.768 kHz、LSI 约 40 kHz、HSE/128（8 MHz 时 62.5 kHz）；LSE 可在 VBAT 域继续，LSI 精度低且 VDD 掉电后不能维持。
- [ ] 20 位预分频器将 RTCCLK 降为计数频率；32 位 CNT 作为秒计数；ALR 比较产生闹钟；DIV 是当前预分频余数。
- [ ] 基本公式：`f_CNT = f_RTCCLK / (PRL + 1)`，目标 1 Hz 时 `PRL = f_RTCCLK - 1`。
- [ ] LSE：`PRL = 32768 - 1 = 32767`；HSE/128（8 MHz）：`PRL = 62500 - 1`；LSI 标称 40 kHz：`PRL = 40000 - 1`，实际会因 LSI 偏差产生走时误差。
- [ ] 32 位秒计数范围：`0～2^32-1`；溢出周期约 `2^32 / (365.2425×86400) ≈ 136.1 年`。
- [ ] RTC APB1 接口曾关闭后，读取前等待 RSF（SPL：`RTC_WaitForSynchro()`）。
- [ ] 写 PRL/CNT/ALR 前等待 RTOFF、进入 CNF 配置；每次写后再等待上次任务完成（SPL：`RTC_WaitForLastTask()`）。
- [ ] 配置路径：开启 LSE → 等 LSERDY（生产代码必须有超时）→ 在 RCC_BDCR 选 LSE → 使能 RTC → 同步 → 配预分频 → 设 CNT。
- [ ] 分清普通系统复位、后备域复位、VDD 断电且 VBAT 存在、VDD/VBAT 同时断电四种结果。
