## 4. 完整知识清单与公式

### 4.1 GPIO 数据路径与八种模式

- [ ] GPIO 端口挂在 APB2；使用前先 `RCC_APB2PeriphClockCmd`，且时钟常量、端口指针、Pin 位掩码必须同属实际端口。
- [ ] 输入路径：引脚→施密特触发器→IDR；上拉/下拉通过内部弱电阻确定悬空默认值；浮空输入悬空不确定；模拟输入关闭数字输入路径以降低影响。
- [ ] 输出路径：ODR/BSRR/BRR 或复用外设→输出控制→P/N MOS；推挽可主动拉高/拉低，开漏只能主动拉低，高电平依靠上拉。
- [ ] 复用推挽常用于 USART/TIM/SPI 输出；复用开漏常用于 I2C；“复用”表示电平来自片上外设而非普通 ODR。
- [ ] 会逐项说明 8 模式：浮空输入、上拉输入、下拉输入、模拟输入、开漏输出、推挽输出、复用开漏输出、复用推挽输出。
- [ ] `GPIO_Speed` 是输出翻转能力/边沿配置，不是让主循环自动以该频率翻转；按需求选 2/10/50 MHz，避免不必要的高速边沿。
- [ ] 只有数据手册标记为 FT 的数字引脚在规定条件下可 5 V 容忍；ADC/模拟输入等不可笼统视作 5 V 容忍。
- [ ] PA13/PA14 保留 SWD；PA15/PB3/PB4 默认有 JTAG 复用；PC13～PC15 驱动能力/速度受限，板载 PC13 LED 通常低有效。

### 4.2 SPL 操作、位掩码与 C 语言

- [ ] 固定初始化次序：开时钟→填满 `GPIO_InitTypeDef`→`GPIO_Init()`→设安全初值；能解释为什么先给电机/蜂鸣器安全状态。
- [ ] 区分 `GPIO_ReadInputDataBit`（IDR）、`GPIO_ReadOutputDataBit`（ODR 锁存状态）、`GPIO_SetBits`、`GPIO_ResetBits`、`GPIO_WriteBit`、`GPIO_Write`。
- [ ] 理解 `GPIO_Pin_x` 是位掩码，可用 `|` 组合；避免用全端口 `GPIO_Write()` 意外覆盖同端口其他引脚。
- [ ] 了解 BSRR/BRR 位写不需软件“读-改-写”，适合原子置位/复位；同时操作多个引脚时先明确是否会产生瞬态。
- [ ] 熟练使用 `stdint.h` 固定宽度整数；知道本目标上常见 `char=8`、`short=16`、`int=32`，但接口应优先显式宽度和符号。
- [ ] 会用 `#define` 抽取端口/引脚/有效电平参数；宏参数加括号，避免副作用和优先级错误。
- [ ] 会解释 `typedef`、结构体 `.`/指针 `->`、枚举及 SPL 初始化结构体；结构体每个字段必须赋值或先调用对应 `StructInit`。
- [ ] 位操作：置位 `x |= mask`；清零 `x &= ~mask`；读取 `(x & mask) != 0`；归一为 0/1 可写 `!!(x & mask)`。

### 4.3 外设器件与调试

- [ ] LED：极性、限流、电流方向、灌电流/拉电流、低有效；不允许无依据直接跨接电源。
- [ ] 有源蜂鸣器只需直流开关；无源蜂鸣器需方波/PWM；模块可能低有效，必须测量或查资料。
- [ ] 按键机械抖动包含按下和松开两段；能解释 `检测→延时→复测→确认→等待释放/状态机`，并知道阻塞等待不适合后期实时系统。
- [ ] 传感器 AO 是连续模拟电压、DO 是比较器二值结果；电位器调的是比较阈值；先脱离 MCU 单测模块 DO-LED 和输出电平。
- [ ] OLED：0.96 英寸常见 128×64；供电和接口以模块丝印为准；本课程软件 I2C 使用 PB8=SCL、PB9=SDA，开漏并依靠上拉。
- [ ] 能使用并解释 `OLED_Init/Clear/ShowChar/ShowString/ShowNum/ShowSignedNum/ShowHexNum/ShowBinNum` 的坐标、长度与越界风险。
- [ ] 比较串口调试（远程文本/日志）、OLED（脱机直观）与 Keil 调试（断点、寄存器、变量；会扰动实时性）。
- [ ] Delay/SysTick：`SystemCoreClock` 与 SysTick 装载值必须匹配；中断上下文/长延时会阻塞，今日只能用于简单消抖和演示，不能当作未来调度器。

### 4.4 必会计算

- LED 限流：`R ≥ (VCC - Vf) / I`；例如必须按实测/器件参数选值，不以 GPIO 最大额定电流作为常态设计电流。
- 分压：`Vout = VCC × R2 / (R1 + R2)`；光敏电阻变化方向取决于它在上臂还是下臂。
- 软件消抖：若连续 `N` 次采样、间隔 `Ts` 均一致，确认时间约 `N × Ts`；必须记录实际策略而非机械套 20 ms。
- OLED 坐标边界由驱动 API 定义；课程字符行列并非像素坐标，调用前查 `OLED.c/.h`。

## 7. 官方勘误与 FAQ

### 7.1 勘误 6：OLED 位值归一

视频写字节可能把 `Byte & (0x80 >> i)` 的结果直接传给写引脚函数；结果可能是 `0x80` 等非 1 值。课程 `GPIO_WriteBit` 对非零可工作，但移植到严格判断 `== 1` 的封装会失败。最终版应在边界归一为 `!!(Byte & mask)` 或在写函数中明确“非零即高”，读引脚也用布尔语义；闭卷解释为什么这是可移植性修复而非波形变化。

### 7.2 今日 FAQ（5～7、15）

- [问题5 LED 不亮](https://jiangxiekeji.com/problem/p1-5.html)：先比对可用基线；核对 APB2 而非 AHB、`ClockCmd` 而非 `ResetCmd`、LED 极性/限流/接触、复位；再换已知可用引脚做替换验证。
- [问题6 光敏或蜂鸣器异常](https://jiangxiekeji.com/problem/p1-6.html)：区分光敏/热敏模块；DO 脱离 MCU 单测并调整光照/阈值；蜂鸣器单测供电、GND、IN 和有效电平。
- [问题7 OLED 不显示](https://jiangxiekeji.com/problem/p1-7.html)：先确认供电/共地和板脚接触，再逐线核对 VCC/GND/SCL/SDA 与代码；用已知例程分离软件/硬件问题。
- [问题15 PA15/PB3/PB4 不工作](https://jiangxiekeji.com/problem/p1-15.html)：默认 JTAG 复用；开 AFIO 时钟并只禁用 JTAG、保留 SWD（`GPIO_Remap_SWJ_JTAGDisable`）。绝不能把 SWD 也关掉后无恢复方案。
