## 4. 完整知识清单与公式

### 4.1 外部时钟与时基延伸

- [ ] 能区分内部时钟、外部时钟模式 1（TIx/ETR 经触发输入）、外部时钟模式 2（ETR 直接作为外部时钟）和编码器模式。
- [ ] `TIM2_ETR` 默认在 PA0；GPIO 配成输入，ETR 极性决定哪种有效边沿，`TIM_ExtTRGPSC_*` 决定每 1/2/4/8 个有效边沿计一次。
- [ ] 数字滤波不是“固定消抖毫秒数”；采样频率和连续样本数由滤波码及 `TIM_ClockDivision` 共同决定，强滤波会限制可接受脉冲宽度/频率。
- [ ] 外部计数关系：若输入有效边沿数为 `Nedge`，外部预分频为 `Pext`，时基 PSC 分频为 `PSC+1`，则 CNT 增量约为 `floor(Nedge / (Pext × (PSC+1)))`（忽略起始相位/溢出）。
- [ ] 计到 ARR 后发生更新/回零；更新中断和直接读 CNT 是两种不同观察路径。

### 4.2 输出比较与 PWM

- [ ] 输出比较链：TIM 时钟→PSC→CNT/ARR→CNT 与 CCRx 比较→OCxREF→极性选择/输出使能→复用 GPIO。
- [ ] 会解释冻结、匹配置有效/无效、匹配翻转、强制有效/无效、PWM1、PWM2；能根据向上计数和极性画波形。
- [ ] PWM1 向上计数、高有效：`CNT < CCR` 时有效；`CCR=0` 为 0% 有效，`CCR=ARR+1` 为 100% 有效。明确 API/寄存器允许范围再处理边界。
- [ ] `f_PWM = CK_PSC / ((PSC + 1)(ARR + 1))`。
- [ ] 高有效 PWM1：`Duty = CCR / (ARR + 1)`；若输出极性反相，物理高电平占空比相反。
- [ ] 占空比分辨率/最小步距：`Reso = 1 / (ARR + 1)`；增大 ARR 提高分辨率但需协调 PSC 和频率。
- [ ] 预装 CCR/ARR 可让新值在更新边界生效，减少中周期毛刺；动态改变 PSC 的生效方式也需明确。
- [ ] 通用 TIM2 的 CH1/2/3 默认 PA0/PA1/PA2；GPIO 必须为复用推挽。使用高级 TIM1 时还需主输出使能等额外条件，不能照搬 TIM2。

### 4.3 三个负载

- [ ] LED 呼吸是对视觉/负载惯性做占空比调制；线性改变 CCR 不等于人眼感知线性，可选查 gamma，但今日验收以波形正确为主。
- [ ] 课程 LED：TIM2_CH1/PA0，PSC=`720-1`、ARR=`100-1` → 1 kHz、1% 步距；呼吸边界不能发生无符号下溢。
- [ ] 舵机课程条件：周期约 20 ms（50 Hz），高脉宽约 0.5～2.5 ms 对应 0～180°；不同舵机实际范围须校准，越界可能堵转。
- [ ] 舵机课程：TIM2_CH2/PA1，1 MHz 计数（PSC=`72-1`），ARR=`20000-1`；`pulse_us = 500 + angle/180 × 2000`，CCR 等于微秒脉宽。
- [ ] 电机不可由 GPIO 直驱；TB6612 的 VM（电机电源）、VCC（逻辑）、GND、STBY、PWMA、AIN1/AIN2、AO1/AO2 职责明确且共地。
- [ ] 课程电机：TIM2_CH3/PA2，PSC=`36-1`、ARR=`100-1` → 20 kHz；PA4/PA5 控制方向。速度命令必须饱和到 `[-100,100]`，0 的刹车/滑行策略要明确。
- [ ] 换向先 PWM=0，等待机械/电气安全间隔，再改方向并升 PWM；上电/复位/异常时保持 PWM=0、STBY 禁止（若模块引出）。
- [ ] 供电压降、面包板电源轨断点、驱动器待机、负载堵转和去耦都可能让“代码正确但电机不转/MCU 复位”。

## 6. 闭卷实验、迁移与故障注入

### 6.1 必做

1. 外部时钟：对射模块接 PA0，预测遮挡 `N` 次的 CNT；分别比较滤波 `0x00`/`0x0F` 的统计后恢复 0x0F。若出现官方所述卡死，PSC 从 `1-1` 改 `2-1` 并记录，不把现象编造成普遍规律。
2. 输出比较：不看源码，写通用 TIM2 PWM 初始化与 `PWM_SetCompare1`；先固定 10%、50%、90%，用示波器/逻辑分析仪测频率/占空比，再做无下溢的呼吸。
3. 舵机：**先不接舵机**，测 50 Hz 和 0.5/1.0/1.5/2.0/2.5 ms；合格后断电接入，逐步试角，记录机械安全范围。
4. 电机：先验证电机/电源，再手动验证 TB6612 方向输入，再用 LED/仪器验证 MCU 的 PA2/PA4/PA5，最后接电机；完成正转、减速、停机、反转。
5. 每个工程新构建 0 Error/0 Warning；保存 map、下载、测量和实物证据。

### 6.2 今日特定迁移题

Codex 随机给 `CK_TIM`（应来自实际时钟树）、目标 PWM 频率、占空比和以下之一：舵机角度或电机速度。学习者必须先列方程，选择不溢出的 PSC/ARR/CCR，计算实际频率、误差和分辨率，再闭卷修改、测量。不得用“不断试数字直到看起来对”。

### 6.3 故障注入（至少三项）

- 把 PWM GPIO 错设普通推挽或通道/引脚不匹配，解释内部 CCR 变化但引脚无波形。
- 故意漏输出使能/定时器使能或反转极性，按数据链定位。
- 把 PSC/ARR 的 `-1` 漏掉，先算理论误差再测。
- 电机仅在安全断电条件下模拟 STBY 低、方向两脚错误或电源轨中间断开，分段定位。
- 动态换向不先归零，**只做代码审查/低风险演示**，说明风险后恢复安全时序。
