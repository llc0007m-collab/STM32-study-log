## 完整知识清单

### 外设能力与初始化

- [ ] STM32F103C8T6 有 I2C1/I2C2，支持主/从、多主、7/10 位地址、标准 100 kHz/快速 400 kHz、DMA 与 SMBus；今天实现 7 位主模式。
- [ ] I2C2 挂 APB1；PB10=SCL、PB11=SDA，均为 `GPIO_Mode_AF_OD` 且需要上拉。
- [ ] 理解 `I2C_ClockSpeed`、`I2C_DutyCycle`、`I2C_Ack`、`I2C_AcknowledgedAddress`、`I2C_OwnAddress1`；主模式下自身地址不参与当前通信，但结构体字段仍需确定值。
- [ ] 课程基线 `I2C2=50 kHz`、DutyCycle=2、ACK Enable、7 位、自身地址 0；时钟频率必须与 APB1 实际频率一致。
- [ ] 配置顺序：GPIO/I2C 时钟→AF_OD→`I2C_Init`→`I2C_Cmd`；开始事务前检查 BUSY，失败必须超时退出。

### 框图、标志与事件

- [ ] 画出 SCL/SDA、数据/移位寄存器 DR、时钟控制、地址比较和控制/状态寄存器的关系。
- [ ] EV5 主模式选择对应 START 已发送（SB）；EV6 发送地址后主发送/主接收模式选中（ADDR 与 BUSY/MSL/TRA 组合）。
- [ ] EV8 表示发送缓冲可继续写（TXE）；EV8_2 表示字节传输完成（BTF+TXE），生成 STOP 前应等待正确阶段。
- [ ] EV7 表示收到字节（RXNE）；单字节读不能简单照搬多字节循环。
- [ ] `I2C_CheckEvent` 比较“最近事件”掩码，不等于只读一个标志；读 SR1 后读 SR2 会清 ADDR，必须理解 SPL 内部副作用。
- [ ] 区分 SB、ADDR、BTF、RXNE、TXE 与错误 AF（NACK）、BERR、ARLO、OVR、TIMEOUT；错误路径必须清除/复位并返回原因。

### 指定寄存器写/读事件流

- [ ] 写：等待 BUSY 清→START→EV5→发送 7 位地址+Transmitter→EV6→发寄存器→EV8/EV8_2→发数据→EV8_2→STOP。
- [ ] 单字节读：写阶段发送寄存器地址→重复 START/EV5→地址+Receiver/EV6→在最后一字节前关闭 ACK 并申请 STOP→EV7→读 DR→恢复 ACK。
- [ ] 知道“先关闭 ACK/申请 STOP 再读最后字节”是为了让硬件在最后一个字节产生 NACK 并正确结束，而不是读完后才补动作。
- [ ] 多字节读取时，中间字节保持 ACK，末字节 NACK；F1 对 1、2、N>2 字节接收有不同的 ACK/POS/BTF 顺序，必须按 RM0008 的主接收流程实现和验收，不能把单字节函数放循环中冒充连续读。

### 稳健性与恢复

- [ ] 课程 `MPU6050_WaitEvent` 无限循环只适合演示；实际函数必须有计数/时间截止，返回 `OK/TIMEOUT/NACK/BUS_ERROR/ARBITRATION_LOST/BUS_BUSY` 等可区分状态。
- [ ] 每次失败保存 SR1/SR2 快照（注意读取副作用），生成 STOP/清错误；必要时禁用 I2C、软件复位再初始化。
- [ ] SDA 被从机拉低时：切为 GPIO 开漏，释放 SDA，输出最多 9 个 SCL 脉冲，生成 STOP，确认两线高，再恢复 AF_OD/I2C2；每步都有限时。
- [ ] 不在中断或主循环中永久等事件；上层必须知道采样失败，不能继续使用旧数据假装新数据。
- [ ] 能对比软件 I2C（边沿由 CPU 控制、便于任意引脚）和硬件 I2C（外设状态机、CPU 负担小、时序严格、错误状态更多）的波形与代码层次。

### 关键计算

```text
标准模式近似：CCR = fPCLK1 / (2 × fSCL)
最大允许上拉（由上升时间）：Rp(max) ≈ tr(max) / (0.8473 × Cb)
最小上拉（由低电平灌电流）：Rp(min) ≈ (VDD - VOL(max)) / IOL
MPU6050 7位地址：AD0=0 -> 0x68；AD0=1 -> 0x69
课程8位写地址：0x68 << 1 = 0xD0；读方向由 SPL 的 Direction 参数处理
```

不要手写 CCR 后假设 PCLK1；用 RCC 时钟树和 SPL 初始化结果交叉核对实际 SCL 波形。

### 故障注入（至少 4 项）

- 拔掉 MPU6050，产生地址 NACK；确认返回 NACK 而非永久等待。
- 将地址误用为 7 位/8 位的错误形式，读取 SR1 的 AF 并恢复。
- 人为将 SDA 暂时接地，验证 BUSY/常低检测和 9 脉冲恢复；操作前断电接线，避免短路误操作。
- 删掉单字节读前的 ACK Disable/STOP，记录读流程异常并解释。
- 错等 EV8 而非 EV8_2 就 STOP，说明最后字节是否真正移出。
- 设置错误 PCLK1/ClockSpeed，实测 SCL 并追到 CCR/TRISE。
