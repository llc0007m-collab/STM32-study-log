## 4. 完整知识清单与公式

### 4.1 输入捕获与测量方法

- [ ] 输入捕获链：TI 引脚→输入选择（直接/间接/TRC）→数字滤波→边沿极性→捕获预分频→把 CNT 锁存进 CCRx；读取 CCR 不会等同于读取当前 CNT。
- [ ] `TIM_ICSelection_DirectTI` 与 `IndirectTI` 的信号映射；`TIM_ICPSC_DIV1/2/4/8` 表示每若干有效边沿捕获一次，不是时基 PSC。
- [ ] `TIM_ICFilter` 需要以信号带宽换抗噪，滤波太强会吞掉窄脉冲；`TIM_ClockDivision` 会参与滤波采样时钟。
- [ ] 测频法：固定闸门时间 `Tg` 内计输入边沿 `Nx`，`fx = Nx/Tg`，相对量化误差约 `1/Nx`，适合较高频。
- [ ] 测周法：用已知计数频率 `fc` 计相邻同类边沿间隔 `N`，`fx = fc/N`，相对量化误差约 `1/N`，适合较低频。
- [ ] 中界频率：令两种量化误差相等，`fm = sqrt(fc/Tg)`；能检查量纲并说明课程图中的根号不能遗漏。
- [ ] TIM3 教程设 `CK_TIM=72 MHz`、PSC=`72-1`，得到 `fc=1 MHz`（1 µs/tick），ARR=`65536-1`；单溢出范围约 65.536 ms，对应不处理溢出时约 15.26 Hz 的下限。
- [ ] 主从复位测周：TI1FP1 上升沿既触发 CCR1 捕获又把 CNT 复位；下一周期重复，硬件自动形成周期计数。
- [ ] 课程代码使用 `f = 1,000,000/(CCR1+1)`；`+1` 是否需要取决于计数区间定义，必须以计数时序和已知频率实测确认，频率/高脉宽公式的约定必须一致。
- [ ] 无信号不能返回上一次 CCR 的“正常频率”；必须有捕获更新/超时标志。`N=0`、溢出、多次溢出和读写竞态都要显式处理。

### 4.2 PWMI

- [ ] PWM 输入模式用一只物理输入映射到两个捕获通道：通常 CH1 直接 TI1 捕获周期上升沿，CH2 间接 TI1 捕获下降沿；PA7/TIM3_CH2 **不是**此配置下的第二根 PWM 输入线。
- [ ] 触发源 TI1FP1 + 从模式 Reset，使每个周期上升沿清 CNT；CCR1 保存周期计数、CCR2 保存高电平计数（按高有效/极性配置）。
- [ ] `f = fc/Nperiod`，`t_high = Nhigh/fc`，`Duty = Nhigh/Nperiod × 100%`；若沿极性或信号有效电平反转，测得的是低电平占空比。
- [ ] 更新 CCR1/CCR2 不保证软件任意时刻读取到同一周期的成对快照；高动态信号应考虑捕获中断/DMA/一致性策略，今日至少避免分母为零和陈旧数据。
- [ ] 最大可测频率受输入电气、滤波、捕获路径和最小 tick 数限制；频率越高，`Nperiod` 越小，相对量化误差越大。

### 4.3 正交编码器接口

- [ ] A/B 相相差 90°；根据某相边沿时另一相电平判向。交换 A/B 或反转输入极性会改变方向符号。
- [ ] `TIM_EncoderMode_TI1`、`TI2`、`TI12` 区分在哪些边沿计数；TI12 通常利用两相边沿得到四倍频计数，实际 counts/rev 必须按编码器规格和实测标定。
- [ ] TIM3_CH1=PA6、CH2=PA7；两脚输入上拉、滤波，配置 `TIM_EncoderInterfaceConfig`，CNT 自动增/减。
- [ ] 16 位 CNT 从 0 反向会回卷到 65535；在两次采样增量绝对值 `<32768` 时，将模 65536 差值解释为 `int16_t` 可恢复有符号增量。
- [ ] 课程“读 CNT 后清零”简单直观，但读与清零之间到来的边沿可能丢失；更稳健方法是 CNT 连续运行，保存上次快照并做模差。
- [ ] `counts_per_second = Δcount/Ts`。
- [ ] `RPM = 60 × Δcount / (CPR × Ts)`；CPR 必须明确是最终四倍频后每输出轴转的计数，含编码器 PPR 定义、×4 和减速比。
- [ ] `rad/s = 2π × Δcount/(CPR × Ts)`；速度符号对应方向。
- [ ] 采样周期短响应快但量化抖动大，周期长更平滑但延迟大；可比较 100 ms 与 1 s，再决定滤波，而不是随意平均。

## 6. 闭卷实验、今日迁移与故障注入

### 6.1 输入捕获/PWMI

1. 不看 6-6，闭卷写 TIM3_CH1 输入捕获：1 MHz 计数、上升沿、直接输入、合理滤波、TI1FP1 触发、Reset 从模式。
2. TIM2_CH1/PA0 输出已知 PWM，飞线到 PA6。测试至少 100 Hz、1 kHz、10 kHz；记录理论值、CCR1、计算值、仪器值、绝对/相对误差。
3. 不看 6-7，改为 `TIM_PWMIConfig`；测试 10%、37%、50%、83%、90%，记录 CCR1/CCR2 和测量误差。
4. 断开 PA6、输入恒高/恒低、低于单溢出量程时，程序必须显示 `NO_SIGNAL/OUT_OF_RANGE` 或等价无效状态，不能显示旧值或除零。

### 6.2 编码器

1. 闭卷配置 TIM3 编码器 TI12；先手转一个机械格，记录 A/B 相、计数增量和方向符号，再标定每圈计数。
2. 正/反各转 5 圈，比较期望计数与实测；交换 A/B，验证符号翻转后恢复。
3. 用 100 ms 与 1 s 两种 `Ts` 计算 counts/s 和 RPM；每种连续记录 20 个样本，比较均值、波动和响应延迟。
4. 比较“读后清零”和“连续 CNT 快照模差”的代码风险；最终版优先使用连续快照法。

### 6.3 今日特定迁移题：测量未知 PWM

由 Codex 指定测试范围，由信号发生器、另一块板或不告知当前参数的测试源产生一个安全 3.3 V PWM。学习者只能先得到 `CK_TIM`、允许频率范围和允许占空比范围，独立选择 PSC/ARR/滤波/超时，报告频率、占空比、有效性和不确定度；揭晓源参数后计算误差。若只有一块板，可由他人随机设置 TIM2 参数并遮蔽设置值，不能把“自己刚设置的值”冒充未知测量。

### 6.4 故障注入（至少三项）

- 把捕获极性改为下降沿或把直接/间接通道配反，先画预期 CCR 再观察。
- 删除 Reset 从模式，解释 CCR 变成“自启动以来时间”或溢出数据。
- 把滤波设过强后提高 PWM 频率，观察漏沿/无信号并恢复。
- 不做无信号超时或分母零保护，用代码审查证明风险后修正（不要故意造成不可控异常）。
- 编码器把 CNT 当无符号、A/B 互换或采样间隔过长导致跨过 ±32768，定位符号/混叠错误。

所有目标必须新构建 `0 Error / 0 Warning`，保存 map、下载、回环/编码器照片和测量数据。
