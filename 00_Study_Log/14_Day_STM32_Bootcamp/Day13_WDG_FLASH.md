## 4. 完整知识清单与公式

### 4.1 看门狗通用原则

- [ ] 看门狗用于程序卡死/跑飞、硬件异常和干扰后的自动恢复；不能替代根因修复，也不能掩盖反复重启。
- [ ] 喂狗点应证明“一次完整关键任务周期成功”，不能在高频中断里无条件喂狗，否则主循环卡死也不会复位。
- [ ] 上电读取 RCC_CSR 的复位来源并持久化计数，再调用 `RCC_ClearFlag()`；先读取后清除，避免丢证据。
- [ ] 设计超时必须大于最坏执行时间（含中断、Flash 擦写、启动、温漂裕量），同时小于系统可接受故障恢复时间。

### 4.2 IWDG

- [ ] IWDG 使用独立 LSI（标称约 40 kHz、误差较大），即使主时钟异常仍可运行；12 位递减计数器、PR 预分频、RLR 重装。
- [ ] 键寄存器：`0xCCCC` 启动；`0xAAAA` 将 RLR 重装到计数器（喂狗）；`0x5555` 解除 PR/RLR 写保护；其他值恢复写保护。
- [ ] 预分频系数为 4、8、16、32、64、128、256；RLR 范围 0～4095。
- [ ] 公式：`T_IWDG = (1 / f_LSI) × PR × (RL + 1)`。
- [ ] 教程值：`f_LSI=40 kHz, PR=16, RL=2499`，`T≈1.000 s`；实际上下界必须代入数据手册 LSI 容差，不只用典型值。
- [ ] 使能后通常只能由复位停止；硬件/软件启动方式受选项字节影响，本日不修改选项字节。

### 4.3 WWDG

- [ ] WWDG 由 PCLK1 驱动，时间较准但依赖总线时钟；T[6:0] 递减，WDGA 使能位与计数器同在控制寄存器。
- [ ] T 低于 `0x40`（T6 变 0）产生复位；计数器仍高于窗口 W 时过早重装也复位；在允许窗口内重装才安全。
- [ ] T 到 `0x40` 可产生早期唤醒中断 EWI；EWI 可做最后记录/喂狗，但 ISR 必须短且不可依赖不安全长写。
- [ ] 单计数节拍：`t_tick = 4096 × WDGTB / f_PCLK1`，其中 WDGTB 系数为 1、2、4、8。
- [ ] 从初始计数 T 到复位：`T_WWDG = t_tick × (T[5:0] + 1)`；到达窗口的等待：`T_open = t_tick × (T_initial[5:0] - W[5:0])`。
- [ ] 教程值：PCLK1=36 MHz、WDGTB=8、T=0x40|54、W=0x40|21，`t_tick≈0.910 ms`，窗口约在 30～50 ms；40 ms 喂狗合法。
- [ ] 主频/APB1 分频改变后必须重算；不能把 HCLK 直接代入 PCLK1。

### 4.4 IWDG 与 WWDG 选择

| 项目 | IWDG | WWDG |
|---|---|---|
| 时钟 | LSI，独立但误差大 | PCLK1，较准但依赖系统时钟 |
| 失败条件 | 到期未喂 | 到期未喂或过早喂 |
| 中断 | 无 EWI | 可用 EWI |
| 计数 | 12 位重装 | 6 位有效计数窗口 |
| 用途 | 独立兜底、容许时间误差 | 检测任务过快/过慢、精确窗口 |

### 4.5 Flash 组织与访问

- [ ] STM32F103C8T6 程序 Flash：`0x08000000～0x0800FFFF`，64 页 × 1 KB；最后一页起址 `0x0800FC00`。
- [ ] 系统存储器/Bootloader 约 2 KB，基址 `0x1FFFF000`；选项字节 16 字节，基址 `0x1FFFF800`；不得当普通数据页使用。
- [ ] ICP 通过 JTAG/SWD/系统 Bootloader 更新整体内容；IAP 由运行中的应用通过通信接口接收并自编程。
- [ ] FPEC 解锁序列：KEY1=`0x45670123`，再 KEY2=`0xCDEF89AB`；顺序错误会锁到下次复位；完成后重新置 LOCK。
- [ ] 擦除态为全 1；编程只能可靠地把 1 变 0，把 0 恢复 1 必须先擦除整页。STM32F1 基本编程粒度是 16 位半字，地址需正确对齐。
- [ ] 安全流程：确认地址/范围 → 等 BSY=0 → 清/检查错误 → 解锁 → 页擦除 → 等待并检查 → 半字/字编程 → 每次检查 → 回读/CRC → 加锁。
- [ ] 状态至少关注 BSY、PGERR、WRPRTERR、EOP；SPL 返回的 `FLASH_Status` 不能丢弃。
- [ ] Flash 擦写会阻塞同一 Bank 取指；不能在实时硬约束或即将掉电时盲目整页改写。
- [ ] 保留页前必须核对 `.map`/链接器；教程 `STORE_START_ADDRESS=0x0800FC00`、`STORE_COUNT=512` 恰占最后 1 KB，但程序增长后仍必须再次证明不重叠。
- [ ] 存储格式至少包含 magic、schema version、payload length、sequence、payload、CRC；上电只接受长度/版本/CRC 均合法的最新记录。
- [ ] 掉电原子性可用双页/双槽、先写 payload+CRC 后提交有效标记；高频数据应做磨损均衡，不在每次循环整页擦写。
- [ ] 擦写寿命、数据保持和电压范围以数据手册保证值为准；报告记录保存频率和寿命预算。

### 4.6 选项字节与电子签名

- [ ] 选项字节字段：RDP 读保护、USER（硬件看门狗/低功耗复位选择）、Data0/1 用户字节、WRP0～3 写保护。
- [ ] 选项字节也需检查 BSY、解锁 OPTWRE、编程/擦除、等待与回读；错误配置可导致调试锁定或程序页受保护，**本日只读学习**。
- [ ] Flash 容量寄存器：`0x1FFFF7E0`，16 位，单位以手册定义为准；本芯片应与 64 KB 标称一致。
- [ ] UID 基址 `0x1FFFF7E8`，96 位只读；按 16/32 位正确对齐读取并格式化为固定宽度十六进制。
- [ ] UID 可用于设备标识/派生标识，不是秘密，不可直接当认证密钥或密码。

## 6. 闭卷编码、实物实验与故障注入

### 6.1 闭卷任务

1. Codex 临时给一个目标超时范围和 `f_LSI` 容差，选择 IWDG PR/RL，证明典型/最短/最长超时均满足约束。

4. 把 96 位 UID 输出为 24 个十六进制字符；同时读取容量并拒绝超出真实容量的数据页配置。

### 6.2 实物验收

| 实验 | 操作 | 通过证据 |
|---|---|---|
| IWDG 正常 | 以安全间隔完成任务后喂狗 | 连续运行、无复位，日志有喂狗周期 |
| IWDG 卡死 | 按键阻塞超过超时 | 自动复位，启动后 IWDGRST 标志/计数正确 |
| WWDG 三窗口 | 分别过早、合法、过晚喂狗 | 过早/过晚复位、合法持续；实测时间与计算吻合 |
| Flash 保持 | 改变配置→保存→断电→上电 | 数据与 CRC 正确恢复，magic/version 可见 |
| Flash 损坏 | 调试器改坏 payload/CRC 或用受控测试向量 | 上电拒绝损坏记录并走默认值，不越界 |
| UID/容量 | 读出两次并重启 | 结果稳定、格式 96 位、容量符合芯片 |

### 6.3 故障注入（至少三项）

- 把 IWDG 公式漏掉 `+1` 或误用 HCLK，比较计算/实测并修正。
- 在 WWDG 窗口开启前喂狗，证明“喂得越快越安全”是错误观念。
- 修改 PCLK1 后不重算 WWDG，观察窗口漂移。
- 让数据页与 `.map` 中代码区重叠（只做静态演算，**不得真正擦除**），要求检查器拒绝启动擦写。
- 构造奇地址、越过页尾、长度溢出或 CRC 错误，验证 API 返回错误且不写。
- 保存过程中在受控点断电；若没有安全可重复装置则用双槽状态模拟，并标注未完成的实物断电项。

## 10. 100 分评分、硬门槛与判定

| 维度 | 分值 | 判分重点 |

- `PASS`：≥80 且全部硬门槛通过。

- `BLOCKED`：工具/硬件阻塞；不算学习失败，但未补齐前不能 PASS。
